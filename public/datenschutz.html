2 · Wie diese App funktioniert

Die Kinderwitzemaschine ist eine App für ChatGPT (OpenAI). Sie stellt einen MCP-Server (Model Context Protocol) bereit, den ChatGPT im Hintergrund aufruft, um Kinderwitze abzurufen.

Der Ablauf ist wie folgt: Der Nutzer stellt eine Frage in ChatGPT → ChatGPT ruft unseren Server auf und übermittelt dabei ausschließlich die Tool-Parameter (z.B. eine Kategorie oder ein Suchwort) → unser Server liefert einen Witz zurück → ChatGPT zeigt den Witz an.

Wichtig: Unser Server empfängt zu keinem Zeitpunkt den vollständigen Chat-Verlauf, Nutzernamen, E-Mail-Adressen oder sonstige personenbezogene Daten. Es wird ausschließlich der jeweilige Tool-Parameter (Kategoriename oder Suchbegriff) übermittelt.

3 · Erhobene personenbezogene Daten

  • Keine Benutzerkonten oder Anmeldungen
  • Keine Nutzerprofile

4 · Von der App zurückgegebene Daten

Die App gibt ausschließlich folgende Daten zurück:

  • Einen Kinderwitz (Frage und Antwort) aus einer statischen Datenbank
  • Den Kategorienamen des Witzes (z.B. „Tiere“, „Schule“)
  • Bei der Suche: die Anzahl der Treffer

Es werden keine Nutzer-IDs, Session-IDs, Zeitstempel, Tracking-Codes oder sonstige personenbezogene Daten in den Antworten enthalten.

2 · How this app works

Kinderwitzemaschine is a ChatGPT app (by OpenAI). It provides an MCP server (Model Context Protocol) that ChatGPT calls in the background to retrieve children's jokes.

The flow is as follows: The user asks a question in ChatGPT → ChatGPT calls our server, transmitting only the tool parameters (e.g. a category name or a search keyword) → our server returns a joke → ChatGPT displays the joke to the user.

Important: Our server never receives the full chat history, usernames, email addresses, or any other personal data. Only the specific tool parameter (category name or search keyword) is transmitted.
